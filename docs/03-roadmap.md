# 03 — Roadmap

Rule: **ship something visible every week.** Tick boxes as you go.

## Phase 0 — Validate (Week 1: 2026-11-26 → 2026-12-03) · no code

- [ ] Pick target customer + one-sentence promise (`docs/01-product-brief.md`)
- [ ] List 15 agencies/freelancers (`work/phase-0-validation/prospects.csv`)
- [ ] Send 15 personalized messages (`outreach-messages.md`)
- [ ] Hold 8+ 10-minute calls using `interview-script.md`
- [ ] Waitlist landing page live with one price (`landing-page-copy.md`)
- [ ] Post 3 build-in-public clips
- [ ] Go / no-go using the decision rule in `docs/02-swot.md`

**Exit target:** 5 say they'd pay, or 3 agree to a paid pilot.

## Phase 1 — Concierge MVP (Weeks 2–4: 2026-12-04 → 2026-12-24)

- [ ] Check open-source licences and pick a base (ADR 0002)
- [ ] Deploy the base chat UI on a small server
- [ ] Connect official API(s); keys only on the server
- [ ] Branding: name, logo, colours
- [ ] Per-user spending limits
- [ ] Client tag on conversations (even a simple field or workspace per client)
- [ ] Manual billing: invoice or payment link
- [ ] Onboard GrowMos team + 3–5 pilot customers by hand

**Exit target:** pilots actively using it weekly; first payments received.

## Phase 2 — Automate what customers use (Weeks 5–8: 2026-12-25 → 2027-01-21)

- [ ] Prepaid credits + automatic payments (local gateway + international)
- [ ] Team admin panel
- [ ] Usage dashboard per client and per person
- [ ] Shared prompt library with agency templates
- [ ] In-app onboarding video

## Money targets

| Date | Target |
|---|---|
| Day 30 (2026-12-26) | 3 pilot customers or paid pre-orders |
| Day 60 (2027-01-25) | 5–10 paying customers |

## Weekly rhythm

- Daily: 1 focused hour, same time. Start with 5 minutes if it feels heavy.
- Weekly: ship one thing (page, clip, feature, or message batch) + update the scoreboard
  in `status/NOW.md`.
