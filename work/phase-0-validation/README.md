# Phase 0 — Validation Kit

Goal by **2026-12-03**: 5 people say they'd pay, or 3 agree to a paid pilot.

| File | Use |
|---|---|
| `prospects.csv` | Your 15 targets + status tracking (open in Excel) |
| `outreach-messages.md` | Message templates (LinkedIn, WhatsApp, email, follow-up) |
| `interview-script.md` | 10-minute call script + what to record |
| `landing-page-copy.md` | Waitlist page copy, ready to paste into Carrd/Framer/Webflow |

`status` values in `prospects.csv`: `todo` → `sent` → `replied` → `call_booked` →
`call_done` → `pilot` / `no`.
